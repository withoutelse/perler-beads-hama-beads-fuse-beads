## 6. 单人自用边界

- 不做登录、多用户、权限、配额、分享链接和计费。
- 本地 Windows 优先，同时保持 Docker 兼容。
- Tripo API Key 只放在服务端环境变量。
- SQLite + 本地 `storage/` 保存项目、图片、作业和产物。
- 生产化（PostgreSQL、S3/MinIO、队列、多 worker、监控）属于可选 M8，不阻塞 M2–M7。

## 7. Codex 任务引用方式

后续任务提示词建议写成：

```text
实现 M4-T4（对应 R-29 的同边间距与防撕裂）。先阅读 AGENTS.md、docs/03-algorithm-spec.md、
docs/05-implementation-plan.md 和 docs/12-requirements-traceability.md。
只做该任务；任何输出必须通过 RouteGuard 和 DesignValidator。
补充领域测试，运行 unittest 和 compileall，并同步 API/文档。
```

任务完成时必须更新本表中对应行的“当前实现/状态”，不能只改代码不改追踪矩阵。
