# 黄金样例

`demo-design.json` 是一个最小可校验设计，用于：

- 领域模型反序列化测试
- 路线守卫回归
- 前端演示数据对齐
- 后续 SVG/PDF 渲染的固定输入

它不是完整产品样例，也不代表最终拆件质量。

`m2-normalization.json` 是 M2-T1/T2 的坐标归一化与实心体素化黄金样例：

- 源 GLB 为 Y-up 的 `2 × 4 × 6` 盒体。
- 目标高度 30mm，5mm 豆，归一化后网格为 `3 × 9 × 6`。
- 固定变换矩阵、毫米边界、表面体素数、内部体素数和实心体素数用于回归测试。

M2-T3 的颜色回归使用内存生成的 2×2 纹理平面：4 个表面体素分别匹配 `blue/red/yellow/green` 各 1 颗；同一实心盒体用单色验证 162 个内部体素的表面色传播。该样例同时覆盖缺少 UV、无效 UV 和缺少贴图图像的稳定错误码。它验证采样与色号映射的确定性，不代表最终官方色卡；正式色卡应通过项目配置覆盖。

M2-T4 的切片预览复用同一 Y-up 盒体：`z=3` 切片固定为 `3×9` 网格、27 个 `charcoal` 实心格和 `#3b3b3b` 色号；默认切片取中间层 `z=3`，`z=6` 返回 `VOXEL_SLICE_OUT_OF_RANGE`。该样例同时验证没有 `model_glb` 时返回 `MODEL_ARTIFACT_NOT_FOUND`，前端不得用演示板件冒充真实体素结果。

`m2-voxel-artifact.json` 是 M2-T5 的体素产物黄金样例：

- 固定源模型 artifact ID、相对路径、5mm 豆距、目标高度 30mm、Y-up 和 `ΔE = 6.0`。
- 固定缓存键 `08cacf2e4e2fff54e8cd2c8ee91d7d4f9ee65378d693c04f5800ca5345505cab` 和 artifact ID `art_voxel_npz_08cacf2e4e2fff54e8cd2c8e`。
- 固定 `3×9×6` 网格、`15×45×30mm` 物理边界、134 个表面体素、28 个内部体素、162 个实心体素和 `charcoal` 色号。
- 固定占用体素与颜色的 SHA-256 摘要，并覆盖 NPZ 无 pickle 往返、缓存参数敏感性、缓存命中不重算和体素化失败重试不重复调用 Tripo。

性能基准不是黄金文件：`scripts/benchmark_voxelization.py --grid-size 256 --max-seconds 30` 在开发机得到 19.825s，只覆盖归一化、表面体素化和实心填充，不含完整颜色采样。

`m3-decomposition.json` 是 M3-T7 的分解黄金样例：

- 源体素网格为 5×5×3 空心方管，共 48 个 `orange` 体素。
- 固定 1 个层带 `B01`、3 张 `RING` 水平环片（`P01`–`P03`）、4 张 `PERIMETER` 垂直围板（`P04`–`P07`）和 3 张 `CROSS_SKELETON` 十字骨架（`P08`–`P10`）。
- 十字骨架取每个环片的最大 4-连通孔，居中生成 1 格臂宽的加号形空白件，并固定源孔格、骨架格、余量格和孔轮廓 ID。
- 固定 20 条接触边 `E01`–`E20`、两组稳定连通分量（`P01..P07` 和 `P08..P10`）、所有板件 4-连通、路线守卫通过和 `DesignValidator` 通过。
- M3-T7 仍只生成单个十字空白件；M4-T1/T2 已生成候选描述符和舌槽布尔，真正拆板与出图留给后续。
- M4-T1 复用该样例生成 16 个接头候选（`J01..J16`）和 4 个 `CONTACT_TOO_SHORT` 跳过（`E15..E18` 垂直段接缝）；12 个环片/围板承力候选为 2 格宽、3 格长、居中位置 1、槽 3×4，2 个水平叠层和 2 个十字堆叠为 1×1 销钉、槽 2×2。候选只记录描述符，不创建舌槽实体格。
- M4-T2 复用该样例把 16 个候选全部判为 `WALL_TOO_THIN`，不生成半成品接头；7×7×3 环同样全部跳过。11×11×1 厚壁环的 4 个候选全部生成完整布尔，11×11×3 厚壁环生成 12 个完整布尔并跳过 `J01`、`J06`、`J15`、`J16`。所有板件统一采用双面有孔烫法，不区分轻烫区/重烫区；M4-T2 不构造最终 `Joint`，槽口可达性 BFS 属于 M4-T3。
- M4-T3 在 11×11×1 和 11×11×3 厚壁环的完整布尔上固定槽口可达性：前者 4 个、后者 12 个全部可达；`J01` 固定为所需宽度 2、路径宽度 3、槽口 3 格，垂直贯穿槽 `J07`/`J11` 分别位于 `z=1`/`z=2` 的槽腔平面。配置宽度 4 时全部记录 `SLOT_OPENING_TOO_NARROW`，封闭孔记录 `NO_FREE_PATH_TO_PLATE_BOUNDARY`。M4-T3 不构造最终 `Joint`；同边间距与防撕裂属于 M4-T4。
