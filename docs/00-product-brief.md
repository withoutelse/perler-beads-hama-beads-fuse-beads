# 产品需求基线

## 1. 产品定义

PinDou Studio 是一个 Web 应用：用户上传同一物体的多视角图片，系统通过 Tripo 模型 API 重建 3D 模型，将模型实心体素化，再拆解为可独立熨烫、无需胶水、依靠凸凹卡扣互插组装的 3D 拼豆板件，最终输出装配说明和可打印 PDF。

产品不是“把 3D 模型切成水平薄片”的工具。唯一指定路线是：

> **按造型分件 + 双面有孔 + 免胶拼插。**

## 2. 用户与场景

目标用户是具备基础拼豆制作经验、希望把照片或角色/物件转成 3D 拼豆作品的创作者。典型场景：

- 上传角色手办、器皿、玩具、建筑小景等多视角照片。
- 选择 5mm 标准豆或 2.6mm 迷你豆。
- 预览体素化结果和分件方案。
- 下载逐板图纸、色号清单、爆炸图和装配说明。
- 按图纸拼板、双面轻融定型、按顺序无胶组装。

当前版本只面向单人自用：不做登录、多用户、权限、配额、分享链接和计费。数据保存在本机 SQLite 与 `storage/` 目录。

## 3. 核心流程

1. **多视角输入**：上传同一物体的多视角图片，至少 3 张，建议 6–12 张。
2. **3D 重建**：通过外接 Tripo 模型 API 将图片转为 3D 模型。
3. **实心体素化**：以一个拼豆的物理体积为体素单位，将模型转为实心体素集合。
4. **分件**：按层带、外轮廓、内部孔洞和装配可达性拆成板件。
5. **卡扣设计**：为相邻板件生成互补舌槽，并统一应用双面有孔烫法和装配 DAG。
6. **2D 排版**：将板件展开到拼板网格，输出坐标、编号、色号、颗数和孔槽标记。
7. **出图与 PDF**：生成展开网格图、爆炸装配图、成品三视图和装配说明。
8. **校验**：出图前运行连通性、板限、接头配对、DAG、无胶自锁和色卡校验。

## 4. 分件规则摘要

### 4.1 体素到壳/层

- 按 `z` 切水平层：`L_z = {(x, y) | (x, y, z) ∈ V}`。
- 每层取方格外轮廓，再简化为直线折线段；圆弧用阶梯/折线近似，不能输出真曲面。
- 沿 `z` 检测颜色或半径突变，切成层带 `B₁…B_m`。
- 水平板取“外轮廓 − 内孔”。内孔来源包括中心骨架截面、围板舌让位、省豆减重。

### 4.2 分解决策

- 垂直围板把外轮廓折线的每一段摊成 `(u=弧长方向, v=z)` 矩形。
- 圆筒近似为 `N=4–8` 段棱柱，因此输出的是多组直片，不是弯片。
- 层状/回转/夹心物体：水平环片叠层 + 垂直围板 + 中心十字骨架。
- 多面体盒/站立角色：每个共面区域一张平板，90° 卡槽互锁。
- 小特征（五官、耳、脚）：单独成“销钉贴片”，挂到主板预留孔。

### 4.3 接头

建“板件邻接图” `G=(P, 接触边)`，每条边生成一对互补接头：

`j = (p, q, e, dir, pos, w, l)`

- 舌：从 `p` 边外凸，`w × l` 格。
- 槽：在 `q` 上挖空 `w+1 × l+1` 格，槽口必须开在 `q` 的边界。
- 1 格细舌 + 1–2 格孔/槽；大型件经验值为插舌 2–3 格宽、3–4 格长。
- 槽比舌宽 1 格余量，吸收熨烫膨胀。
- 槽放接触边中段，避开边缘防撕裂。
- 承力舌：围板上下、十字互插，根部至少 2 格连主片。
- 销钉舌：1 格小件，只定位不承力。
- 舌占格集 = 对方槽留空格集，允许 +1 余量；全局坐标下零件实体不得相交。
- 槽到板边界必须存在宽度至少 `w` 的全空格路径，不能被豆围死。
- 同板同边两接头间隔至少 `w+2`。
- 所有板件统一采用双面有孔烫法：正反两面都只轻融到豆子边缘粘合、中心孔完整保留，不区分轻烫区/重烫区。

### 4.4 无胶自锁判据

全部满足才允许输出“免胶”：

1. 存在底环，外轮廓包住整体重心投影。
2. 至少 3 组法向互不平行（非共面）的接头，使环片压围板、围板撑环片。
3. 中心两片互补开槽板俯视成十字，定轴抗扭。
4. 装配 DAG 有唯一汇点（最后封顶件），且封顶方向为“从上往下压合”。

### 4.5 板件 2D 化与排版

- 每板映射局部 `(u, v)` 网格，格色 = 体素色。
- 允许 `ΔE` 容差合并相近色，作为“豆子不够用相近色凑”的兜底。
- 板件必须 4-连通，不碎孤岛；超过 `Bmax` 就切分并补拼接舌。
- 全部板件塞进一张大网格，板间至少 1 空行/空列。
- 同类相邻、按装配序分行。
- 每板加 1 格坐标框 + 编号。
- 槽用“挖空 + 红框”，舌用“凸出实体格”显式编码。

## 5. 输出三件套

1. **展开网格图**：坐标、编号、色号图例、每色颗数、孔槽标记。
2. **爆炸装配图**：沿装配轴拉开，带插入箭头和顺序号。
3. **成品三视图**：核对朝向与层次。

## 6. 校验器

出图前必须跑：

- 每板连通
- 不超板
- 接头一一配对，无孤儿舌/槽
- 装配 DAG 无环
- 重心投影在底环内
- 双面有孔烫法已应用（`double_sided_hole` 路线特征）
- 色号 ∈ 色卡

任一不过，回到接头设计步骤改方向或尺寸。

## 7. 退化兜底

- 曲面 → 阶梯折线。
- 悬空细长特征 → 销钉贴片 + 1 格支撑舌。
- 内部实心 → 改空心环片省豆。
- 接头成环 → 改方向；仍不行才显式输出“局部点胶”标注，且必须由用户确认。

## 8. 材料规格

| 参数 | 5mm 标准豆（Midi） | 2.6mm 小豆（Mini） |
| --- | --- | --- |
| 外径 / 格距 | 5.0 mm（Perler Standard 实测 4.77 mm 宽） | 2.6 mm（Perler Mini 2.61 mm；Hama Mini 2.5 mm 略小） |
| 高度（管长） | 5.0–5.1 mm（Perler 5.07 / Hama 5.1） | 2.6–2.8 mm（Artkal C 标 2.6，Perler Mini 2.8） |
| 内孔径 | 2.2 mm（Hama 官方值） | 约 1.0 mm |

板件最大尺寸 `Bmax` 是配置项，不应硬编码为所有板型的唯一值。

## 9. 非目标

- 不做“水平实心切片 + 胶水/连接棒/亚克力杆”的另一类工具。
- 不输出不可制造的纯装饰渲染。
- 不在未校验的情况下承诺“免胶”。
- 不把真实曲面直接当作拼豆板件。
