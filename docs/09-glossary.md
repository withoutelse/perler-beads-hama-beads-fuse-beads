# 术语表

| 术语 | 含义 |
| --- | --- |
| 拼豆 / Perler Beads / Hama Beads / Fuse Beads | 彩色空心圆柱塑料珠，按图案排入凸点模板后熨烫定型 |
| 双面留空烫 / 双面有孔烫 / 双面轻融 | 正反两面只熨到豆边缘熔合、中心孔保留的轻融定型法 |
| 孔保留 / Hole preservation | 双面有孔烫法的验收要求：每颗豆中心孔完整可见，不烫成死平塑料板 |
| 体素 / Voxel | 一个拼豆物理体积对应的三维网格单元 |
| 层带 / Layer band | 沿 z 轴颜色或半径突变切出的连续层区间 |
| 环片 / Ring plate | 水平板件，外轮廓减内孔，俯视呈圆环/方框 |
| 围板 / Perimeter plate | 外轮廓折线段沿 z 摊成的垂直直片 |
| 十字骨架 / Cross skeleton | 中心两片互补开槽板，俯视成十字，用于定轴抗扭 |
| 销钉贴片 / Pin patch | 小特征单独成片，通过 1 格销钉定位 |
| 舌 / Tongue | 从板件边缘外凸的实体格 |
| 槽 / Slot | 在另一板件上挖出的留空格，槽口开在边界 |
| 装配 DAG | 板件装配顺序的有向无环图 |
| 汇点 / Sink | 装配 DAG 中没有后继的节点，即最后封顶件 |
| 无胶自锁 | 不靠胶水/连接棒，通过底环、三向接头、十字抗扭和封顶压合保持稳定 |
| Bmax | 单张拼板允许的最大格数 |
| ΔE | 颜色差异指标，常用 CIEDE2000；用于相近色合并 |
| Tripo | 外部 3D 模型重建 API |
| GLB | 常见 3D 模型文件格式；本项目 Tripo 输出格式 |
| 1:1 校验尺 | PDF 中用于确认打印比例的长度标尺 |
