# 架构决策记录

## ADR-001 单仓 + Python 领域核心 + React 工作台

**状态**：接受。

**背景**：项目同时包含几何算法、Web API、3D 预览和 PDF 出图。

**决策**：采用 `apps/api` + `apps/web` 单仓。领域算法用纯 Python，Web 层用 FastAPI，前端用 React/Vite。

**后果**：领域可独立测试；前端可替换；需要维护两套依赖。

## ADR-002 路线守卫是硬门禁

**状态**：接受。

**背景**：产品文档明确禁止水平实心切片、胶水、连接棒等退化路线。

**决策**：`RouteGuard` 是领域层硬门禁；任何导出前必须通过。禁止通过放宽枚举或删除测试绕过。

**后果**：部分“看起来能做”的方案会被拒绝；错误信息必须可操作。

## ADR-003 领域层不依赖 Web/网络

**状态**：接受。

**决策**：`app/domain` 只使用标准库；Tripo/存储/数据库通过适配器注入。

**后果**：测试快；需要维护接口协议。

## ADR-004 单位与坐标固定

**状态**：接受。

**决策**：物理尺寸用 mm；体素/板件用整数格；世界坐标 `x` 右、`y` 深、`z` 上；板件局部 `(u,v)`。

**后果**：避免单位混用；所有算法必须显式转换。

## ADR-005 产物优先 SVG，PDF 用 reportlab

**状态**：接受。

**决策**：展开图/爆炸图/三视图先输出 SVG，再组装 PDF。避免依赖浏览器截图。

**后果**：可测试、可打印；复杂排版需要自己实现。

## ADR-006 先本地存储，后对象存储

**状态**：接受。

**决策**：M1–M7 用本地文件系统；M8 切 S3/MinIO。

**后果**：早期简单；后续需要迁移抽象。

## ADR-007 免胶失败必须显式

**状态**：接受。

**决策**：不满足自锁判据时返回 `GLUE_FREE_SELF_LOCK_FAILED`；只有用户确认才能输出 `local_glue` 标注。

**后果**：不会静默假装免胶；产品体验需要解释失败原因。

## ADR-008 单人自用 + Tripo GLB 轮询

**状态**：接受。

**背景**：当前需求只面向单人自用，不需要账号、权限、配额和分享。

**决策**：

- 不做登录、多用户、权限、配额和计费。
- 项目、图片、作业、阶段和产物使用本地 SQLite + 文件系统持久化。
- Tripo 使用多视角任务，轮询到成功后下载 GLB。
- 默认 5mm 29×29 板、2.6mm 57×57 板、Perler Standard、`ΔE = 6.0`、A4 1:1 中文 PDF。

**后果**：实现简单、可离线运行；真实 Tripo 字段和物理公差仍需账号/实物验证。M8 生产化保留为可选路线。

## ADR-009 统一双面有孔烫法

**状态**：接受。

**背景**：用户确认所有板件都按双面有孔烫法制作，不再区分轻烫区/重烫区。

**决策**：

- `Joint` 不再携带 `light_iron_zone`，校验器不再要求每个接头生成轻烫区。
- 所有设计必须包含 `RouteFeature.DOUBLE_SIDED_HOLE`；正反两面都只轻融到豆子边缘粘合、中心孔完整保留。
- 图纸只标记孔保留、槽口、装配顺序和风险说明，不生成轻/重烫分区。

**后果**：领域模型更简单；旧的 `light_iron_zone` 字段和 `LIGHT_IRON_ZONE_MISSING` 校验被移除。M4-T5 改为双面有孔烫法标记与孔保留校验。
